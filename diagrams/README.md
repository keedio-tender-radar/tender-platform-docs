Para versiones detalladas/editables se añadirán `.drawio` aquí cuando se necesiten:

```

```

> Preferimos Mermaid en Markdown para que el diagrama viva junto a su documento y se renderice en
> GitHub sin herramientas externas. Los `.drawio` se reservan para diagramas ricos puntuales.
